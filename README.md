# 가계부

서버 없이 브라우저만으로 동작하는 가계부 웹앱입니다. 월별로 수입·지출을 기록하고, 월 메모를 블록 단위로 쓰고, 월말에는 소비 습관 피드백과 올해 목표 저축 달성률을 확인할 수 있습니다. 홈 화면에 설치하는 PWA라서 인터넷이 없어도 열립니다.

**접속 주소:** https://yoonyong2003.github.io/mini-notion/

- 의존성이나 빌드 과정 없이 `index.html`, `style.css`, `app.js` 세 파일로 만들었습니다.
- 모든 데이터는 사용자의 브라우저(`localStorage`)에만 저장되고 어디로도 전송되지 않습니다.

## 기능

### 월과 내역
- 왼쪽 목록에서 월을 추가하고 삭제합니다. 월마다 수입에서 지출을 뺀 금액이 함께 보입니다.
- 내역을 추가, 수정, 삭제합니다. 지출/수입 구분, 날짜, 카테고리, 메모, 금액을 입력합니다.
  - 지출 카테고리: 식비, 교통, 주거/통신, 쇼핑, 문화/여가, 기타
  - 수입 카테고리: 급여, 용돈, 기타수입
- 수입, 지출, 잔액이 자동으로 계산됩니다.
- 내역의 날짜를 다른 달로 바꾸면 그 달로 옮겨집니다.

### 월 메모 (블록 에디터)
- 블록 종류는 문단, 제목, 목록, 체크리스트 네 가지입니다.
- `Enter`로 새 블록을 만들고, 빈 블록에서 `Backspace`로 삭제합니다.
- 빈 블록에서 `/`를 누르면 블록 종류 메뉴가 뜹니다. `↑` `↓`로 고르고 `Enter`로 선택하며 `Esc`로 닫습니다.
- 빈 문단에서 `# `(제목), `- `(목록), `[] `(체크리스트)를 입력하면 종류가 바뀝니다.
- 한글 조합 중에 누른 `Enter`는 글자 확정에만 쓰이고 블록을 만들지 않습니다.

### 월 결산과 소비 피드백
- 월 메모 아래에 수입 대비 지출 비율, 저축액, 저축률을 보여줍니다.
- 카테고리별 지출 비중과 전월 대비 증감을 보여주고, 가장 큰 지출은 빨간색으로 강조합니다.
- 목표 저축률(기본 20%)을 정하면 부족한 금액과 줄일 항목을 제안합니다.
- 외부 AI를 쓰지 않고, 입력된 내역으로 계산하는 규칙 기반 분석입니다.

### 올해 목표 저축
- 목표 금액을 입력하면 `30,000,000`처럼 쉼표가 자동으로 들어갑니다.
- 올해 이미 끝난 달의 남은 금액(수입 − 지출)이 자동으로 합산되어 목표 달성률을 보여줍니다.
- 남은 개월 수에 맞춰 월 저축 필요액도 안내합니다.

### PWA와 화면
- 안드로이드와 아이폰 모두 홈 화면에 설치할 수 있습니다.
- 서비스 워커가 모든 파일을 캐시해서 오프라인에서도 열립니다.
- 휴대폰 화면에서는 월 목록이 위쪽으로 접힙니다.
- 흰색 배경에 하늘색 포인트의 밝은 테마입니다.

## 설치 방법

### 안드로이드 (Chrome)
1. 접속 주소를 엽니다.
2. 메뉴(⋮)에서 **앱 설치** 또는 **홈 화면에 추가**를 누릅니다.

### 아이폰 (Safari)
1. 접속 주소를 Safari로 엽니다. 다른 브라우저에서는 홈 화면 추가가 되지 않습니다.
2. 공유 버튼에서 **홈 화면에 추가**를 누릅니다.

### 내 컴퓨터에서 실행
```bash
python -m http.server 8000
```
폴더에서 위 명령을 실행하고 `http://localhost:8000`에 접속합니다. 서비스 워커는 HTTPS나 `localhost`에서만 동작하므로, 같은 Wi-Fi의 폰에서 `http://192.168...` 같은 주소로 열면 설치와 오프라인 기능은 쓸 수 없습니다.

## 데이터에 관한 안내

- 데이터는 `localStorage`의 `ledger-v1` 키에 저장됩니다.
- 기기와 브라우저, 접속 주소마다 저장 공간이 따로입니다. PC의 `localhost`, 배포 주소, 홈 화면에 설치한 앱의 데이터는 서로 보이지 않습니다.
- 브라우저 데이터를 지우면 가계부 데이터도 함께 사라집니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 화면 구조, PWA meta 태그, 서비스 워커 등록 |
| `style.css` | 스타일 (밝은 테마, 반응형) |
| `app.js` | 월·내역 관리, 블록 에디터, 월 결산, 목표 저축, 저장 |
| `manifest.json` | PWA 설정 (이름, 아이콘, 테마 색) |
| `service-worker.js` | 오프라인 캐시 (파일을 고치면 `CACHE` 버전을 올려야 반영됨) |
| `icons/` | 192px, 512px, 아이폰용 180px 아이콘 |

## 사용한 프롬프트

Claude Code와 대화하며 만든 과정에서 사용한 프롬프트입니다. 읽기 쉽게 줄바꿈만 정리했습니다.

**1. 아이디어 정하기**
> 서버없이 브라우저만으로 동작하는 웹앱 아이디어를 5개 추천해줘, 100분안에 만들 수 있는 크기로

**2. 화면 만들기**
> 4번으로 만들고 싶어. 앱 화면을 HTML/CSS/JS로 만들어줘. 아직 기능은 없어도돼. 왼쪽 페이지 목록, 오른쪽 제목과 본문 편집 영역- 휴대폰에서는 페이지 목록이 위로 접히게- 디자인: 밝은 배경, 포인트 색은 초록, 깔끔한 한글 글꼴- 파일: index.html, style.css, app.js (경로는 모두 상대 경로)
> 다 만들면 브라우저에서 열어줘.

**3. 가계부로 전환**
> 그러면 가계부 형식으로 바꿔서 다시 보여줄래?

> 샘플 값 모두 지워줘

**4. 저장과 편집 기능**
> 페이지를 추가·삭제하고 제목과 본문을 편집할 수 있게 해줘. 데이터는 localStorage에 저장해서 새로고침해도 남게 해줘.

**5. 블록 에디터**
> 본문을 블록 단위로 바꿔줘. Enter로 새 블록, 빈 블록에서 Backspace로 삭제. 종류는 문단, 제목, 목록, 체크리스트. 이것도 가계부에 맞춰서

> 빈 블록에서 '/'를 치면 블록 종류 메뉴가 뜨게 해줘. 방향키·Enter·Esc로 조작. 이것도 가계부에 맞춰서

> 한글 입력 중에 Enter가 두 번 처리되지 않게 해줘.

**6. 월 결산과 목표 저축**
> 홈페이지 메모장 맨 아래 해당 달이 끝나면 소비 패턴과 ai가 매월 내 소비습관에 대해 피드백해줄 수 있는 기능을 추가해줬으면 좋겠어. 뭐 이번달은 수입의 몇퍼센트 정도를 사용했고, 저축은 얼마를 했으며 좀 더 저축을 하려면 어떤 걸 수정해야하는지 이런거 넣어줘

> 색감이 너무 똑같다. 기본 테마는 흰색 배경에 지금 초록색으로 들어간 포인트들은 하늘색으로 바꿔주고, 맨 아래 분석에서 가장 지출이 큰 부분은 빨간색으로 표시해줘

> 오케이 굿 이제 마지막으로 기능 하나만 더 추가해보자. 홈페이지 맨 왼쪽에 달력 추가하는 곳 아래에 올해 목표 저축 칸을 만들어서 사용자가 직접 금액을 입력할 수 있게 만들고, 매달 끝날 때마다 가계부에서 남은 금액을 올해 목표 저축 칸으로 자동으로 업데이트해서 사용자가 목표로 설정한 금액의 몇퍼센트를 저축했는지 알려주게 만들어줘

> 목표 저축 금액이 너무 가시적이지 않아. 3000만원이면 30,000,000원 이렇게 나올수 있게 바꿔줘

**7. 샘플 데이터**
> 내가 지금 홈페이지에 8월 9월 10월 만들어놨어 너가 여기에 샘플로 몇개 수입이랑 지출, 메모 적어봐

> 그러면 지금 8월 9월 10월만 있잖아. 올해 1월부터 10월까지 10개월 샘플로 만들어줄래?

> 뭔가 샘플이 비현실적인데. 식비가 너무 적게 나가잖아

**8. PWA와 배포**
> 이 웹앱을 아이폰과 안드로이드 모두 홈 화면에 설치할 수 있는 PWA로 만들어줘.- manifest.json: 앱 이름 '미니 노션', display standalone, 테마 색 초록- 아이콘: 192px, 512px, 아이폰용 180px(apple-touch-icon) PNG 생성- service-worker.js: 모든 파일을 캐시해서 인터넷 없이도 열리게- index.html에 manifest, 아이폰용 meta 태그, 서비스 워커 등록 추가- 경로는 모두 상대 경로로

> 테마 색 한번에 바꿔 앱 이름도 가계부로 바꾸고

> 이 폴더를 git 저장소로 만들고, GitHub에 공개 저장소 mini-notion을 만들어 push해줘. 그리고 GitHub Pages를 main 브랜치 루트로 켜고 접속 주소를 알려줘.
